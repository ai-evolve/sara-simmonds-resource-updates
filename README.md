# AI-biotech resource updates

This public repository checks official program pages every Monday and publishes the small JSON feed used by the Resources page.

## Safety rules

- Only official URLs are checked.
- Only status and deadline fields can be changed automatically.
- A configured date must be visible on the official page, or one future deadline must be unambiguous.
- Ambiguous pages, network failures, and parser changes leave existing content untouched.
- Every run writes an audit report.

The portfolio source remains in a separate private repository.
